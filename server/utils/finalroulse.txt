🏏 CRICKET ASTROLOGY RULE BOOK (Updated - Priority & Non-Stacking System)

🔴 PART 1: CORE LOGIC & PRIORITY SYSTEM
🔹 Max Points Cap: 25 Points Maximum per player. Points will NEVER exceed 25.
🔹 No Stacking: Rules do not blindly accumulate points. Priority hierarchy decides the primary points:
   1. Zig-Zag (25 Pts Flat) -> Highest Priority. If matched, player gets flat 25 pts (No other general batting rules run).
   2. Direct Rule (10 Pts) -> Second Priority.
   3. Star vs Conjunction -> Evaluates both candidates; picks whichever has HIGHER points. The lower one is deactivated.

🔴 PART 2: IMPORTANT RAHU / KETU RULE (MATCH)
🔹 If Match Nakshatra Lord = Rahu or Ketu -> Use Match Rasi Lord.
🔹 Special: Magam -> Star Lord becomes Chevvai (Mars).
🔹 Special: Ashwini -> Star Lord becomes Chevvai (Mars).

🟢 PART 3: BATTING RULES
🟩 Rule 1: ZIG–ZAG RULE (Top Priority)
   Match Rasi Lord = Player Star Lord AND Match Star Lord = Player Rasi Lord -> 25 Pts Flat (Max Cap)
🟩 Rule 2: DIRECT RULE
   Match Rasi Lord = Player Rasi Lord AND Match Star Lord = Player Star Lord -> 10 Pts Flat
🟩 Rule 3: STAR RULE
   Match Star Lord = Player Rasi OR Star Lord:
   - Base: 10 Pts
   - Aatchi / Ucham Bonus: +5 Pts
   - Lagna Match Bonus: +5 Pts (Total Max: 20 Pts)
🟩 Rule 4: CONJUNCTION RULE
   Match Star Lord conjoined with Player Rasi Lord or Star Lord:
   - Base: 5 Pts
   - Aatchi / Ucham: +5 Pts (Total 10 Pts)
   - Lagna Match: +5 Pts (Total Max: 15-20 Pts)
   *Note: Between Star & Conjunction, highest candidate score is selected. No stacking!
🟩 Rule 5: SAME HOUSE RULE
   - In Match Star Lord signs: 4 Pts
   - In Match Rasi Lord signs: SURE FLOP (0 Pts)
🟩 Rule 6: MATCH LORDS IN PLAYER HOUSES -> 6 Pts
🟩 Rule 7: RAHU / KETU PLAYER RULE -> 4 Pts
🟩 Rule 8: LAGNA RULE (BATTING)
   Match Lagna Lord = Player Rasi Lord -> 5 Pts (Aatchi/Ucham +5, Neecham -2)
   *Not applied if Star/Conjunction already included Lagna bonus.
🟩 Rule 9: DOUBLE LORD CONJUNCTION -> +12 Pts
🟩 Rule 10: ASHLESHA MATCH + SHATABHISHA PLAYER -> +20 Pts
🟩 Rule 11: RAHU / KETU SPECIAL PLACEMENT -> +20 Pts
